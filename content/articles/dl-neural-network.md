深度学习的"深度"，指的是神经网络的层数多。但不管网络有多深多复杂，它的**最小单元永远只有一个：神经元**。理解了一个神经元，理解 GPT 也就不远了。

## 为什么需要深度学习

传统机器学习有两个绕不过去的坎：

**第一，有些问题它根本解决不了**。图像识别、语音识别、自然语言理解——这些任务的输入是高维原始数据（几十万像素、几万个词），人很难手工设计出有效特征。

**第二，即使能解决，方案也过于复杂**。在深度学习之前，一个图像识别系统要串起十几个手工设计的模块：边缘检测、特征提取、特征编码、分类器……每个模块都要单独调，整体维护成本极高。

深度学习把这套流程压缩成了**端到端的一个网络**：输入原始像素，直接输出结果，中间所有特征由网络自己学。

## 三种典型网络结构

按处理的数据类型，神经网络分三大类：

- **全连接网络（ANN / MLP）** —— 最基础的形式，处理普通的数值特征
- **卷积神经网络（CNN）** —— 卷积层 + 池化层 + 全连接层，专治图像
- **循环神经网络（RNN）** —— 词嵌入层 + 循环层 + 全连接层，专治文本序列

后两者都是在全连接网络的基础上，针对数据特性做了结构化改造。

## 神经元：加权求和 + 激活函数

一个神经元干两件事：**先加权求和，再过激活函数**。

```
z = w1·x1 + w2·x2 + ... + wn·xn + b    # 加权求和（线性变换）
a = f(z)                                # 激活函数（引入非线性）
```

写成矩阵形式就是：

```
z = Wᵀ · x + b
```

**全连接层**的意思是：当前层的每一个神经元，都和上一层的所有神经元相连。而同一层内部的神经元之间互不连接。

### 为什么必须有激活函数

这是最常被问的问题。假设不加激活函数，网络就是纯线性的：

```
输出 = W3 · (W2 · (W1 · x + b1) + b2) + b3
     = (W3·W2·W1)·x + 常数
```

**多个线性层的矩阵连乘，等价于单个线性层**。也就是说，不管你堆 100 层还是 1 层，模型的表达能力完全一样，都是一条直线。**激活函数的唯一作用就是引入非线性，让网络能拟合任意复杂的函数**。

## 四种激活函数

### Sigmoid

```
σ(x) = 1 / (1 + e^(-x))
```

把任意实数压缩到 **(0, 1)**，适合表示概率。

- **值域** 0~1，**有效定义域**大约 -6~6（超出后梯度几乎为 0）
- **导数最大只有 0.25**，多层连乘后梯度会指数衰减
- 主要用于**输出层**：二分类最后一层

### Softmax

把一串实数变成**概率分布**（所有值加起来等于 1），用于多分类的输出层。

```
softmax(z_i) = e^(z_i) / Σ e^(z_j)
```

### Tanh

值域 **(-1, 1)**，以 0 为中心。相比 Sigmoid，它的输出有正有负，收敛通常更快。主要用于早期网络的隐藏层，现在大部分场景被 ReLU 取代。

### ReLU

```
ReLU(x) = max(0, x)
```

**现代深度学习的默认选择**。小于 0 直接归零，大于 0 原样通过。

优点极其突出：
- **计算极快** —— 就是一次比较，不用算指数
- **缓解梯度消失** —— 正区间的导数恒为 1，不会像 Sigmoid 那样连乘衰减

缺点：**神经元死亡** —— 如果某个神经元的输入长期为负，梯度恒为 0，权重再也不会更新，这个神经元就"死"了。改进版本有 Leaky ReLU（负区间给一个很小的斜率）、GELU（GPT 系列用的）。

### 使用规则

```
隐藏层 → ReLU（或 tanh / GELU）
输出层 → Sigmoid（二分类）/ Softmax（多分类）/ 无（回归）
```

```python
import torch

x = torch.tensor([-1.0, 0.0, 2.0])
print(torch.relu(x))      # tensor([0., 0., 2.])
print(torch.sigmoid(x))   # tensor([0.269, 0.500, 0.881])
print(torch.tanh(x))      # tensor([-0.762, 0.000, 0.964])
```

有个重要细节：**做多分类时，PyTorch 的 `CrossEntropyLoss` 内部已经集成了 Softmax**，所以模型的最后一层**不要**再加 Softmax，直接输出原始 logits 即可。加了反而会导致数值不稳定。

## 前向传播与反向传播

一次完整的训练分两个方向：

**前向传播（Forward）** —— 数据从输入层流向输出层，沿途做加权求和 + 激活，最后算出预测值和损失：

```
x → (W1, b1) → z1 → 激活 → (W2, b2) → z2 → 激活 → 输出 → 损失 Loss
```

**反向传播（Backward）** —— 损失从输出层往回传，用链式法则逐层算梯度，然后更新参数：

```
W_new = W_old - 学习率 × 梯度
```

反向传播的原理就是**链式法则**。以两层网络为例，损失对第一层权重 w1 的梯度，是沿途所有偏导的连乘：

```
∂Loss/∂w1 = (∂Loss/∂z2_out) · (∂z2_out/∂z2_in) · (∂z2_in/∂z1_out) · (∂z1_out/∂z1_in) · (∂z1_in/∂w1)
```

每一项的含义很清晰：激活函数的偏导 × 加权求和的偏导，从输出层一路传递到输入层。这就是"反向"的由来。

**整个过程在 PyTorch 里只需要三行**，因为框架会自动构建计算图并求导：

```python
loss = loss_fn(y_pred, y_true)  # 前向：算损失
loss.backward()                 # 反向：自动微分算梯度
optimizer.step()                # 用梯度更新参数
```

## 损失函数怎么选

**回归问题**：
- `L1Loss` —— 平均绝对误差，对离群点稳健
- `MSELoss` —— 均方误差，最常用，但对离群点敏感
- `SmoothL1Loss` —— 两者折中，误差小时用平方、大时用线性

**分类问题**：
- `BCELoss` —— 二分类交叉熵（需要先手动加 Sigmoid）
- `CrossEntropyLoss` —— 多分类交叉熵（**内部已含 Softmax**，最常用）

```python
import torch.nn as nn

loss_fn_reg = nn.MSELoss()           # 回归
loss_fn_cls = nn.CrossEntropyLoss()  # 多分类，输入是 logits，标签是类别编号
```

## 深度学习的四个特点

1. **由神经网络层层堆叠而成** —— 输入层（特征）→ 隐藏层 → 输出层
2. **特征工程自动化** —— 不需要人工设计特征，网络自己学
3. **依赖大数据 + 大算力** —— 参数量动辄上亿，必须用 GPU
4. **可解释性差** —— 隐藏层是黑盒，"为什么是 12 层而不是 18 层"至今没有严格理论，主要靠实验

## 大模型应用开发中的落地

**第一，大模型就是超深的全连接 + 注意力网络**。一个 Transformer 层里，FFN（前馈网络）部分就是标准的全连接层（通常是 4 倍隐藏层维度），激活函数用的是 GELU。理解了全连接层，你就看懂了 Transformer 一半的结构。

**第二，Softmax 和温度参数（temperature）直接决定生成效果**。大模型采样时的 `temperature` 参数，就是作用在 Softmax 之前对 logits 的缩放：

```
temperature → 0：分布变得极尖锐，模型总是选概率最高的词，输出确定但呆板
temperature → 1：正常采样
temperature > 1：分布变平，输出更随机更有创造性，但可能胡说
```

调 API 时，创意写作设 0.8~1.0，代码生成和分类设 0~0.3，就是这个原理。

**第三，激活函数的选择在微调时也有讲究**。现代大模型普遍用 GELU 或 SwiGLU，而不是 ReLU。如果你在做 LoRA 微调或者自己搭小模型，跟随主流选择（GELU）通常比自己尝试更稳妥。

**第四，理解反向传播能帮你debug 训练崩溃**。训练时 loss 变成 NaN，八成是这几个原因：学习率太大导致梯度爆炸、损失函数调用错了（多分类任务误用 MSE）、数据在某个环节出现了 inf。知道反向传播在算什么，就知道该去哪查。

## 小结

神经网络的一切都建立在**一个神经元 = 加权求和 + 激活函数**这个公式上。激活函数的唯一目的是引入非线性（否则堆再多层也等价于一层）；隐藏层用 ReLU、输出层用 Sigmoid/Softmax；训练 = 前向算损失 + 反向算梯度 + 更新参数。
