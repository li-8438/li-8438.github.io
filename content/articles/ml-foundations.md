很多人学机器学习是从 `from sklearn.linear_model import LinearRegression` 开始的，跑通之后却说不清"模型到底学了什么"。这一篇先把地基本打牢：**机器学习到底在做什么、有哪些玩法、一次建模要经历哪几步、最容易翻车的地方在哪**。

## 人工智能、机器学习、深度学习是什么关系

这三个词常被混着用，但它们是**层层包含**的关系。

- **人工智能（AI）** 是最大的圈，目标是让机器像人一样思考、行动、理性决策
- **机器学习（ML）** 是 AI 的一个分支，思路是"从数据中总结规律，用规律预测结果"
- **深度学习（DL）** 是 ML 的一个分支，思路是"搭建多层神经网络，让网络自动学特征"

一句话区分后两者：**机器学习是"基于数据找规律"，深度学习是"基于仿生搭网络"**。

一个具体的对照：要识别一张图片里有没有猫。

传统机器学习的做法是，人先总结出特征——有没有胡须、耳朵是不是三角形、毛发纹理如何，把这些特征喂给模型去学。深度学习的做法是，直接把像素丢进神经网络，让网络自己从像素里长出"边缘→形状→猫脸"这样的层级特征。

```python
# 深度学习网络的典型结构：输入层 → 隐藏层 → 输出层
# 每一层做的事就是：加权求和 + 激活函数
# 输入层(特征) → 隐藏层(自动提取特征) → 输出层(预测结果)
```

深度学习能普及，靠的是三件事凑齐：**大数据 + 大算力（GPU）+ 深层网络结构**。但代价是**可解释性差**——隐藏层基本是个黑盒，为什么是 3 层、12 层还是 96 层，业界至今给不出严格理论，主要靠实验。

## 数据在机器学习里叫什么

这几个术语会贯穿后续所有文章，先对齐：

- **样本（sample）**：一条数据。比如一个用户、一张图片、一条评论
- **数据集（dataset）**：所有样本的集合
- **特征（feature）**：数据的一列，是模型做判断的依据。比如"年龄""收入""文本长度"
- **标签（label）**：要预测的那一列。比如"是否流失""房价""情感极性"

一个数据集通常要切成两份：**训练集**用来让模型学规律，**测试集**用来检验模型学得怎么样。常见切分比例是 7:3 或 8:2。

```python
from sklearn.model_selection import train_test_split

# test_size=0.2 表示 20% 留作测试集
# random_state 固定随机种子，保证每次切分结果一致，方便复现实验
x_train, x_test, y_train, y_test = train_test_split(
    x, y, test_size=0.2, random_state=42
)
```

这里有个**新手最容易犯的错**：先在整个数据集上做标准化、再切分。这样测试集的统计量（均值、标准差）已经泄漏进训练过程，测试成绩会虚高。**正确顺序是先切分，再用训练集拟合 scaler，去 transform 测试集**。

## 四种学习范式

按"有没有标签"来划分，机器学习有四种玩法：

**有监督学习**——有特征也有标签，目标是学会从特征到标签的映射。往下再分两类：

- 标签是**连续值**（房价、温度、销量）→ 回归问题
- 标签是**离散值**（是否、类别）→ 分类问题

**无监督学习**——只有特征没有标签，让机器自己找结构。最典型的是聚类，比如把用户自动分成几个群体。

**半监督学习**——少量有标签，大量无标签。现实中最常见，因为标注要花钱。先用少量标注数据训一个粗糙模型，再去给无标注数据打伪标签，迭代几轮。

**强化学习**——不靠标注数据，靠"环境反馈奖励"。模型做出动作，环境给一个奖励或惩罚，模型目标是最大化累计奖励。AlphaGo、大模型 RLHF 对齐都是这个路子。

> 四种范式对应不同的核心算法：回归常用线性回归，分类常用 KNN / 决策树 / 随机森林，聚类常用 KMeans，决策类问题用强化学习。

## 一次建模的六个步骤

不管是简单的线性回归还是复杂的神经网络，流程都是这六步：

1. **准备数据** —— 加载数据，看一眼形状、缺失、分布
2. **数据预处理** —— 缺失值填充、异常值处理、类型转换
3. **特征工程** —— 提取、预处理、降维、选择、组合
4. **模型训练** —— 选算法，喂训练集
5. **模型预测** —— 用训好的模型对新数据推断
6. **模型评估** —— 用测试集打分，不达标就回头调

其中**特征工程**是传统机器学习里最吃人工的一步，也是最能拉开差距的一步。有句话叫"数据和特征决定了机器学习的上限，而模型和算法只是逼近这个上限"。深度学习的一大优势恰恰是**把特征工程自动化了**——不需要人去设计特征，网络自己学。

```python
# 典型的特征工程：填充缺失值 + 类别变量编码
x = df[['Pclass', 'Age', 'Sex']].copy()
x['Age'] = x['Age'].fillna(x['Age'].mean())  # 年龄缺失用均值填
x_new = pd.get_dummies(x)                    # 性别等字符串转独热编码
```

## 过拟合与欠拟合：贯穿始终的核心矛盾

`fit`（拟合）的意思是模型去"贴合"数据。那么问题来了：**模型把训练数据上的点都拟合得很好，就是好模型吗？**

不是。这里有三种状态：

**欠拟合（underfitting）** —— 模型太简单，连训练集上的规律都没学会。表现是训练集和测试集得分**都低**。原因是特征太少或模型太简单。解决办法是增加特征（常见手法是加平方项、立方项这类多项式特征）、换更复杂的模型。

**过拟合（overfitting）** —— 模型太复杂，把训练数据里的**噪声**也当规律学进去了。表现是训练集得分极高、测试集得分骤降，两者差距巨大。原因是特征过多或模型过于复杂。解决办法是减少特征、增加数据量、加正则化。

**正好拟合** —— 训练集和测试集得分都高且接近，这才是目标。

判断的实用技巧：**盯住训练集和测试集的得分差距**。差距小且都高，健康；差距大，八成过拟合；都低，八成欠拟合。

### 用正则化治过拟合

正则化的思路是**给模型的复杂度加惩罚**，不让它把某些特征的权重学得过大。

**L1 正则化（Lasso）** —— 惩罚项是权重的绝对值之和。效果是**会把一部分权重直接压到 0**，等于自动做了特征选择。类比：员工不听话就直接开除。

**L2 正则化（Ridge）** —— 惩罚项是权重的平方和。效果是**让权重不断逼近 0 但永远不会等于 0**，把所有特征都保留但都削弱。类比：员工不听话就降薪。

```python
from sklearn.linear_model import Ridge, Lasso

# alpha 是正则化强度：越大惩罚越重，模型越简单
ridge = Ridge(alpha=1.0)   # L2，保留所有特征
lasso = Lasso(alpha=0.1)   # L1，可能把部分特征权重压成 0
```

实践中的选择：特征很多且怀疑大部分没用时用 L1；特征都有用只是想防止权重过大时用 L2。sklearn 里还有 `ElasticNet`，是两者加权混合。

## 环境准备

机器学习最主流的库是 scikit-learn，它把上面所有算法都封装成了统一的三步接口：`fit`（训练）、`predict`（预测）、`score`（评估）。

```bash
pip install scikit-learn
```

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(x_train, y_train)      # 训练
pred = model.predict(x_test)     # 预测
```

这个 `fit / predict` 的接口设计贯穿整个 sklearn，学会一个算法，其余几十个都是同样的调法，只是换个类名。

## 大模型应用开发中的落地

你可能会问：现在都直接用大模型了，还学这些有什么用？

**第一，RAG 和 Agent 里大量用到传统 ML 的零件**。比如文本分类（用户意图识别）、聚类（用户分群、文档去重）、相似度计算（检索排序）。这些场景用 BERT 微调固然好，但很多时候一个 TF-IDF + 逻辑回归就能在毫秒级解决，成本差几个数量级。

**第二，"过拟合"这个思维方式在大模型上完全适用**。比如你为了让大模型在某个评测集上好看，把提示词调得过度贴合这批样本，换个数据集就崩——本质就是过拟合，只是对象从权重变成了提示词。大模型时代的应对方式也相似：留出独立测试集、少样本示例要多样化、不要对着评测集反复调。

**第三，评估思路是通用的**。下一篇要讲的交叉验证、网格搜索、精确率召回率，在大模型评测里一个不落全都用得上。做 RAG 时评估"检索准确率""答案忠实度"，用的就是同一套指标体系。

## 小结

机器学习的核心脉络就三条：**数据是样本+特征+标签，玩法分有监督/无监督/半监督/强化四种，流程是准备数据→预处理→特征工程→训练→预测→评估六步**。而贯穿始终的一对矛盾是过拟合与欠拟合，正则化（L1 砍特征、L2 压权重）是对付过拟合的主要武器。
