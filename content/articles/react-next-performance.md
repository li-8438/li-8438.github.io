前端性能优化很少来自“再少写一行 state”，更多来自减少发到浏览器的工作量。

## 服务端优先

不需要浏览器状态的页面优先在构建期或服务端完成渲染，减少发送到客户端的 JavaScript。

## 缩小交互边界

只把表单、主题切换、搜索弹层等真正依赖浏览器 API 的区域做成客户端逻辑。

## 静态资源策略

图片、字体和缓存头往往比微渲染优化更容易获得稳定收益。能预渲染的列表就不要等运行时再拼。

## 可感知的性能

除了 LCP 和包体积，还要看交互是否稳定：滚动、目录高亮、搜索打开都不应该卡住主线程。
