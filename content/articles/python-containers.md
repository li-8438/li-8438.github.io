单个变量只能装一个值，要批量处理数据就得靠容器。Python 有五大内置容器：字符串、列表、元组、集合、字典。它们之间的差异，本质就两条——**可变还是不可变**、**有序还是无序**。吃透这两条，遇到数据就知道该用哪个。

## 五大容器总览

| 容器 | 字面量 | 可变 | 有序 | 是否去重 |
|------|--------|------|------|----------|
| 字符串 str | `'a'` | 否 | 是 | 否 |
| 列表 list | `[1, 2]` | 是 | 是 | 否 |
| 元组 tuple | `(1, 2)` | 否 | 是 | 否 |
| 集合 set | `{1, 2}` | 是 | 否 | 是 |
| 字典 dict | `{'k': 1}` | 是 | 否 | 键去重 |

## 字符串

字符串不可变、有序，所以能靠索引和切片取值，但「改」任何操作都会返回一个新字符串：

```python
s = "hello world"
s[0]          # 'h'      索引从 0 开始
s[-1]         # 'd'      负索引从 -1 开始，从右往左
s[0:5]        # 'hello'  切片[起:止:步长]，包头不包尾
len(s)        # 11      长度
s.count("l")  # 3       出现次数
s.index("w")  # 6       首次出现的索引
s.strip()     # 去掉两端空白
s.split(" ")  # ['hello','world'] 按分隔符切分
s.replace("world", "python")  # 替换
```

## 列表

列表可变、有序，是最常用的容器，支持增删改查全套操作：

```python
l = [1, 2, 3]

# 增
l.append(4)        # 尾部新增 → [1,2,3,4]
l.insert(0, 0)     # 指定位置插入 → [0,1,2,3,4]
l.extend([5, 6])   # 合并另一个列表

# 删
l.remove(3)        # 删除指定元素
l.pop()            # 按索引删除（默认删最后一个）
del l[0]           # del 关键字按索引删
l.clear()          # 清空

# 改
l[0] = 100         # 按索引改

# 查
len(l)             # 长度
l.count(2)         # 出现次数
l.index(2)         # 索引
l.sort()           # 从小到大排序
l.sort(reverse=True)  # 从大到小
```

## 元组

元组和列表几乎一样，唯一区别是**不可变**——创建后不能增删改。所以它适合存放「不希望被改动的固定数据」，比如坐标、配置项：

```python
t = (1, 2, 3)
t = (1,)           # 单元素元组必须带逗号，否则是普通括号
len(t)             # 查询类操作和列表一致
```

## 集合

集合可变、无序，最大的特点是**自动去重**，适合做去重和集合运算：

```python
s = {1, 2, 3}
s.add(4)           # 新增
s.remove(2)        # 删除（不存在会报错）
s.pop()            # 随机删除一个

a = {1, 2, 3}
b = {3, 4, 5}
a | b              # 并集 {1,2,3,4,5}
a & b              # 交集 {3}
a - b              # 差集 {1,2}
```

## 字典

字典存的是「键值对」，靠键快速取值，键不能重复：

```python
d = {"name": "user_a", "age": 18}

d["city"] = "北京"     # 新增：键不存在时赋值
d["age"] = 19          # 修改：键已存在时赋值
d.pop("city")          # 删除某个键
d["name"]              # 按键取值（键不存在会报错）
d.get("name", "未知")  # 更安全的取值，带默认值
d.keys()               # 所有键
d.values()             # 所有值
d.items()              # 所有键值对
```

一个经典用法：拿空字典当「计数器」做统计。例如统计一句话里每个字符出现的次数：

```python
text = "hello"
counter = {}
for ch in text:
    counter[ch] = counter.get(ch, 0) + 1
print(counter)   # {'h':1, 'e':1, 'l':2, 'o':1}
```

## 类型互转

容器之间可以互相转换，转换的前提是元素能被适配：

```python
list((1, 2, 3))    # 元组转列表
tuple([1, 2, 3])   # 列表转元组
set([1, 2, 3])     # 列表转集合（顺便去重）
list({1, 2, 3})    # 集合转列表
[1, 2] + [3, 4]    # 列表拼接 → [1,2,3,4]
```

## 推导式

推导式是「用一行循环生成容器」的语法糖，写起来简洁、读起来直观：

```python
[i * 2 for i in range(5)]           # 列表推导式 → [0,2,4,6,8]
{i * 2 for i in range(5)}           # 集合推导式
{i: i * 2 for i in range(5)}        # 字典推导式

# 三元表达式：成立的值 if 条件 else 不成立的值
"偶数" if x % 2 == 0 else "奇数"
```

## 容器在大模型应用中的出场

学容器最终是为了用。在大模型应用开发里，有两个结构几乎无处不在。

**消息列表**——调用大模型 API 时，对话历史就是一个「字典的列表」：

```python
messages = [
    {"role": "system", "content": "你是一个助手"},
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好，有什么可以帮你？"},
    {"role": "user", "content": "解释一下 RAG"},
]
```

**JSON 解析**——大模型的输出常常是 JSON 字符串，要转成 Python 对象再用：

```python
import json

data = json.loads('{"name": "user_a", "age": 18}')   # 字符串 → 字典
text = json.dumps(data, ensure_ascii=False)          # 字典 → 字符串
```

列表存「多个消息」，字典存「键值配置」，JSON 负责「跨语言交换数据」——这就是容器在 AI 开发里的日常角色。更省心的做法是直接用 Pydantic 定义结构，见《用 Pydantic 做结构化输出》一文。

## 小结

选容器先看两个问题：**要改吗**（不可变选字符串/元组，可变选列表/集合/字典）、**要顺序吗**（有序选列表/元组，无序且要快速查找选字典，只要去重选集合）。日常开发里列表和字典是绝对主力，字符串次之，元组和集合在特定场景（固定数据、去重）各有用武之地。
