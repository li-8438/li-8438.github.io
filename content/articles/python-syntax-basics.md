写 Python 的第一步不是背语法，而是先建立两个直觉：**值有类型，变量没有**；**表达式会算出一个结果，语句才会执行一个动作**。本文把最底层的那层地基——字面量、变量、类型转换、标识符和运算符——一次性说清楚。

## 字面量与数据类型

字面量是直接写在代码里的值，你一眼就能看出它是什么类型：

```python
123          # 整数 int
1.23         # 浮点数 float
1 + 23j      # 复数 complex
True         # 布尔值 bool（另一个是 False）
'123'        # 字符串 str
[1, 2, 3]    # 列表 list
(1, 2, 3)    # 元组 tuple
{1, 2, 3}    # 集合 set
{'1': 1}     # 字典 dict
```

Python 是一门**动态类型 + 强类型**的语言：变量本身没有固定类型，值才有类型，运行时才确定。强类型意味着类型之间不会偷偷转换——`1 + "2"` 直接抛 `TypeError`，不会像某些语言那样好心给你拼成 `"12"`。

## 变量与类型转换

变量是「存放数据的容器」。定义一个变量就是给一个名字绑定一个值：

```python
name = 'user_a'        # 变量名 = 变量值
age: int = 18         # 类型注解只是提示，不强制
age = 19              # 重新赋值，类型也可以跟着变
```

类型转换用的是一组内置函数，它们都能嵌套使用：

```python
type(123)     # 查看类型
int('18')     # 字符串转整数
float('1.5')  # 转浮点数
str(18)       # 转字符串
```

两个规律要记住：**任何类型都能转成字符串**；**只有内容本身是数字的，才能转成数字**，否则报错。

## 标识符命名规范

标识符就是变量名、函数名、类名。规则是硬性的，规范是软性的：

- 规则：只能由数字、字母、下划线组成（中文也行但不推荐），不能以数字开头，严格区分大小写，不能是关键字。
- 规范：见名知意；全小写英文；多个单词用下划线连接，过长可缩写。

## 运算符

### 数学运算符

```python
10 + 3   # 13  加
10 - 3   # 7   减
10 * 3   # 30  乘
10 / 3   # 3.333... 除（结果是浮点数）
10 ** 3  # 1000 幂
10 // 3  # 3   整除（向下取整）
10 % 3   # 1   取余
```

### 赋值与复合运算符

`=` 是赋值。复合运算符是「先算再赋值」的简写，`num += 1` 等价于 `num = num + 1`，同样的写法还有 `-=`、`*=`、`/=`、`**=`、`//=`、`%=`。

### 比较运算符

`>`、`<`、`>=`、`<=`、`==`、`!=`，结果一定是布尔值。两个细节：

- **不做跨类型隐式转换**：`'2' > 1` 直接抛 `TypeError`，要比较就先手动转（`int('2') > 1`）。只有 `==` 和 `!=` 例外——类型不同不报错，直接返回 `False`。
- **字符串按字典序逐字符比较**，比的是 Unicode 码位，所以大写字母整体排在小写字母前面。

### 逻辑运算符

```python
and   # 与：两边都为真才为真
or    # 或：一边为真即为真
not   # 非：取反
```

逻辑运算有个反直觉的返回值——它返回的是**参与运算的值本身**，而不是布尔值：`or` 碰到第一个真值就返回它，全假才返回最后一个假值；`and` 碰到第一个假值就返回它，全真才返回最后一个真值。这一点在「给变量设默认值」时特别有用：

```python
name = user_input or '匿名用户'   # 用户没填就回退到默认值
```

### 成员与身份运算符

`in` 判断是否包含，`is` 判断是否同一个对象。关键区别：`==` 比**值**，`is` 比**身份**——判 `None` 一律用 `is`，比内容一律用 `==`。

### 海象运算符 `:=`

Python 3.8 引入，判断的同时顺便赋值：

```python
if (n := len(text)) > 100:
    print(f"文本过长：{n}")
```

### 运算符优先级

记不住全表没关系，抓住这几层就够用：

| 层级 | 运算符 | 说明 |
|------|--------|------|
| 最高 | `()` | 括号最优先，拿不准就加括号 |
| 高 | `**` | 幂，且**从右往左**结合：`2**3**2` 等于 512 |
| 中 | `*  /  //  %` 高于 `+  -` | 先乘除后加减 |
| 低 | `>  <  ==  in  is` | 比较低于算术 |
| 更低 | `not` → `and` → `or` | 逻辑里 not 最优先 |

两个易错点：`not a == b` 等价于 `not (a == b)`；`a < b < c` 是链式比较，等价于 `a < b and b < c`。

## 字符串与格式化

字符串有三种写法，格式化也有三种：

```python
'单引号'
"双引号"
"""三引号，可以跨行"""

# 百分号占位
"我叫 %s，今年 %d，身高 %.2f" % (name, 18, 1.75)

# format 方法
"{}, {}, {}".format(a, b, c)

# f-string（最推荐）
f"我叫{name}，今年{age}，身高{height:.2f}"
```

## 输入与输出

```python
name = input("请输入你的名字：")   # 阻塞等待用户输入，结果永远是字符串
print("你好", name, end="\n")      # end 控制结尾字符，默认换行
```

`input()` 拿到的永远是字符串，需要数字时记得先 `int()` 或 `float()` 转一下。

## 小结

这层地基的关键就一句话：**先分清「值」和「变量」**。值是带类型的，变量只是名字；运算和类型转换都围绕「值」展开。把字面量、类型转换、运算符吃透，后面的判断、循环、函数都是在这些积木上搭房子。
