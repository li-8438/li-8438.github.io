文本、语音、时间序列这类数据有个共同特点：**顺序有意义**。"我吃苹果"和"苹果吃我"用的是同样的词，意思完全相反。

全连接网络处理不了这种数据——它要求输入长度固定，而且完全忽略顺序。循环神经网络（RNN）就是为此设计的：**它有一个"记忆"，能边读序列边更新状态**。

虽然现在大模型都用 Transformer，但 RNN 的门控思想没有消失——它改头换面活在注意力掩码、MoE 路由、残差门控里。而且理解 RNN 的问题，才能真正理解 Transformer 为什么那样设计。

## RNN 的基本结构

RNN 的核心是一个**循环**：处理每个时间步时，既看当前的输入，也看上一步的隐藏状态。

```
h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b)
y_t = W_hy · h_t + b_y
```

其中：

- `x_t` 是当前时刻的输入（比如第 t 个词的向量）
- `h_{t-1}` 是上一步的隐藏状态（历史记忆）
- `h_t` 是当前隐藏状态，会被传给下一步
- **所有时间步共享同一组权重 W**

可以把 `h_t` 理解成**对历史信息的压缩摘要**。每来一个新词，就用它和旧记忆算出新记忆。

```
x₁ → [RNN] → h₁ → [RNN] → h₂ → [RNN] → h₃ → ...
            ↑           ↑           ↑
          (同一个 RNN 单元，权重共享)
```

RNN 的两大优势：**输入输出长度可以不固定**，**能捕捉时序依赖**。

## 致命缺陷：梯度消失

RNN 的训练算法叫 **BPTT（沿时间反向传播）**——把网络按时间步展开，就成了一个极深的网络，然后反向传播。

问题出在这里：从时刻 t 回传到时刻 1 的梯度，是一连串雅可比矩阵的**连乘**：

```
∂h_T/∂h_1 = ∏ (Wᵀ · σ')
```

- 如果这些矩阵的谱范数 **小于 1** → 连乘后**指数衰减到 0**（梯度消失）
- 如果 **大于 1** → 连乘后**指数增长到无穷**（梯度爆炸）

**梯度消失意味着：早期时间步的信息根本传不到后面**。

具体表现：读一个长句子 "我在法国长大……所以我能说流利的___"，模型需要记住开头的"法国"才能填出"法语"。但梯度传不回去，模型**根本学不到这种长距离依赖**。

而 tanh 的导数最大只有 1、sigmoid 最大只有 0.25，这让情况雪上加霜——连乘的每一项都小于 1，衰减极快。

**梯度爆炸**相对少见但更致命，会导致权重变成 NaN。解决办法是**梯度裁剪**：

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

## LSTM：用门控开辟"高速公路"

**LSTM（Long Short-Term Memory，1997）** 的设计目标很明确：**让梯度能无损地穿过很多时间步**。

它的做法是引入一条独立的**细胞状态（Cell State）C_t**——你可以把它想象成一条传送带，信息可以在上面几乎不变地流动。然后用**三个门**控制什么能上这条带、什么要下来。

### 三个门

**遗忘门（Forget Gate）** —— 决定旧记忆保留多少（0=全忘，1=全留）：

```
f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
```

**输入门（Input Gate）** —— 决定新信息写入多少：

```
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
C̃_t = tanh(W_C · [h_{t-1}, x_t] + b_C)    # 候选新记忆
```

**输出门（Output Gate）** —— 决定细胞状态对外暴露多少：

```
o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
```

### 状态更新

```
C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t    # 细胞状态：旧的 × 遗忘 + 新的 × 输入
h_t = o_t ⊙ tanh(C_t)               # 隐藏状态：细胞状态过 tanh 后按输出门过滤
```

`⊙` 是逐元素相乘（Hadamard 积）。

### 为什么能解决梯度消失

关键在 `C_t = f_t ⊙ C_{t-1} + ...` 这一行。**求偏导时**：

```
∂C_t/∂C_{t-1} = f_t     （后面那项不依赖 C_{t-1}）
```

**梯度沿细胞状态回传时，乘的是遗忘门的值，而不是权重矩阵的幂**。

当遗忘门 `f_t ≈ 1` 时（网络学会了"这个信息要一直记着"），梯度几乎**无损通过**多个时间步。这就是所谓"细胞状态是梯度高速公路"的含义。

对比普通 RNN 的连乘（每步乘一个矩阵，指数衰减），LSTM 用的是**加法路径 + 门控缩放**，梯度不会指数衰减。

这就是 LSTM 与普通 RNN **唯一的本质区别**——不是"多了几扇门"这么表面，而是**把梯度传播路径从连乘改成了加法**。

## GRU：更轻量的替代

**GRU（Gated Recurrent Unit，2014）** 是 LSTM 的简化版，把三个门压缩成两个：

**更新门（Update Gate）** —— 相当于合并了 LSTM 的遗忘门和输入门：

```
z_t = σ(W_z · [h_{t-1}, x_t])
```

**重置门（Reset Gate）** —— 控制多少历史信息参与计算候选状态：

```
r_t = σ(W_r · [h_{t-1}, x_t])
h̃_t = tanh(W_h · [r_t ⊙ h_{t-1}, x_t])
h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t
```

GRU **没有独立的细胞状态**，只有一个隐藏状态。参数比 LSTM 少约 1/3，训练更快。

### LSTM vs GRU 怎么选

| 对比项 | LSTM | GRU |
|---|---|---|
| 门数量 | 3 个（遗忘/输入/输出） | 2 个（更新/重置） |
| 参数量 | 较多 | 少约 1/3 |
| 训练速度 | 较慢 | 较快 |
| 小数据集 | 表达力更强 | 可能过拟合风险低 |
| 效果 | 大多数任务上**接近** | 大多数任务上**接近** |

**实践建议**：效果差不多，优先试 **GRU**（快、省资源）。如果数据量很大且追求极致效果，再对比 LSTM。

有一点要注意：虽然 LSTM 有独立的细胞状态，**理论上对长距离依赖控制更精细**，但在绝大多数实际任务上两者差距很小，别在选型上纠结太久。

## PyTorch 实现

```python
import torch
import torch.nn as nn

class TextRNN(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            num_layers=2,          # 堆叠 2 层
            batch_first=True,      # 输入形状用 (batch, seq, feature)
            bidirectional=True,    # 双向：同时正着读和反着读
            dropout=0.3
        )
        # 双向 → 输出维度翻倍
        self.fc = nn.Linear(hidden_dim * 2, num_classes)

    def forward(self, x):
        # x: (batch, seq_len) 的 token ID
        embedded = self.embedding(x)          # → (batch, seq_len, embed_dim)
        lstm_out, (h_n, c_n) = self.lstm(embedded)
        # 取最后一个时间步的输出做分类
        last_out = lstm_out[:, -1, :]         # → (batch, hidden_dim*2)
        return self.fc(last_out)
```

几个参数说明：

- **`batch_first=True`** —— 让输入用 `(batch, seq, feature)` 的形状，更符合直觉（默认 PyTorch 是 seq 在前）
- **`bidirectional=True`** —— 双向 RNN，同时从前往后和从后往前读，能同时利用上下文。**做文本分类时强烈推荐**，但生成任务不能用（生成时看不到未来）
- **`num_layers=2`** —— 堆叠多层，类似 CNN 的深层结构

换成 GRU 只需把 `nn.LSTM` 改成 `nn.GRU`（GRU 没有细胞状态，返回值少一个）。

## RNN 的三个根本局限

即使有 LSTM/GRU，RNN 家族仍有三个无法克服的问题：

**第一，无法并行**。必须按时间步**串行**计算：算 `h_3` 必须先算完 `h_2`。这意味着训练时无法充分利用 GPU 的并行能力，长序列训练极慢。**这是它被 Transformer 取代的最主要原因**。

**第二，长距离依赖依然困难**。虽然有门控，但信息从位置 i 传到位置 j，仍要跨越 `j-i` 次门控更新。序列超过几百步，信息还是会严重衰减。

**第三，没有显式注意力**。RNN 把所有历史压进一个固定长度的隐藏状态，这是个**信息瓶颈**。而注意力机制允许模型**直接查看任意位置**，不受压缩损失。

## 大模型应用开发中的落地

**第一，理解"为什么现在都用 Transformer"，能帮你判断技术选型**。Transformer 的核心优势就是**并行训练**——同一层所有位置同时计算，可以把序列长度堆到几十万、参数堆到千亿。RNN 的串行结构决定了它规模化不了。这个"能否并行"的视角，是判断一个架构有没有前途的关键。

**第二，RNN 并没有完全消亡，它正在回归**。标准注意力的计算量是序列长度的**平方**，处理超长文本代价极高。而 RNN 是**线性**的。所以新一代架构 **Mamba、RWKV、线性注意力**重新捡起了循环结构，结合门控机制，在长上下文场景展现出优势。理解 LSTM 的门控，就能理解这些新架构。

**第三，门控思想在现代大模型里到处都是**：

- **注意力掩码（Causal Mask）** —— 本质是个 0/1 门，决定哪些位置能看见
- **MoE 路由门** —— 用一个门控网络决定激活哪些专家
- **残差门控** —— 让网络自己学"这一层要保留多少"
- **GLU / SwiGLU 激活函数** —— 用 sigmoid 门控制信息流，LLaMA、Qwen 都在用

学会了"门"这个思维工具，看现代架构会通透很多。

**第四，某些场景 RNN 仍然更合适**。流式处理（语音识别、实时监控）、低延迟要求的在线推理、小数据量的时序预测——这些场景下 RNN/LSTM 的**低延迟和强时序归纳偏置**是优势。不要因为 Transformer 火就一概而论。

**第五，双向 RNN 的思路在 Embedding 模型里保留了下来**。BERT 之所以叫"双向编码器"，就是因为它在每个位置都能同时看到左右上下文——这是双向 RNN 思想的延续，只不过实现方式从"两个方向的循环"改成了"注意力掩码"。

## 小结

RNN 用**共享权重的循环结构 + 隐藏状态**处理序列，但 **BPTT 的梯度连乘导致梯度消失**，记不住长距离依赖。LSTM 引入**细胞状态 + 三个门**，把梯度路径从连乘改成加法，遗忘门接近 1 时梯度无损通过——这才是它缓解梯度消失的真正原因。GRU 用两个门达到相近效果，参数更少、速度更快。

RNN 的死穴是**无法并行训练**，这直接催生了 Transformer。
