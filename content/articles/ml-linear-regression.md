线性回归是机器学习里最简单的模型，但它**一点都不简单**——后面所有深度学习模型的训练过程，底层逻辑和线性回归完全一样：定义一个损失函数，然后想办法让它最小。把线性回归的求解过程真搞懂了，反向传播、优化器、学习率这些概念就是顺理成章的延伸。

## 从一元到多元

中学的直线方程是 `y = kx + b`。机器学习里换了套记号：`k` 叫**权重 w（weight）**，`b` 叫**偏置 b（bias）**，于是：

```
y = wx + b
```

但实际场景不会只有一个特征。房价取决于面积、楼层、房龄、学区……每个特征都有自己的权重，于是推广成多元线性回归：

```
y = w1·x1 + w2·x2 + w3·x3 + ... + wn·xn + b
```

为了写起来方便，通常把 `b` 也塞进权重向量里，同时在特征向量前面补一个常数 1：

```
w = [[b], [w1], [w2], [w3], [w4]]
x = [[1],  [x1], [x2], [x3], [x4]]

y = wᵀ · x    # w 的转置乘以 x
```

这就是神经网络里"加权求和"的原型——**一个神经元干的事，就是这一行公式**。

用 sklearn 实现只需三行：

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(x_train, y_train)   # x 形如 [[160], [166], [172]]，y 形如 [56.3, 60.6, 65.1]
pred = model.predict([[176]])
```

但 `fit` 里面到底发生了什么？这才是重点。

## 损失函数：怎么衡量"预测得准不准"

模型一开始是瞎猜的，w 和 b 都是随机的。要让它变准，得先有个**衡量误差的标准**，这就是损失函数。

```
误差 = 预测值 - 真实值
```

常用的几种：

- **MSE（均方误差）** —— 误差平方后取平均。平方会**放大**大误差，对离群点敏感
- **RMSE（均方根误差）** —— MSE 开根号，量纲回到原始单位，更好解释
- **MAE（平均绝对误差）** —— 误差绝对值取平均，对离群点更稳健

以身高预测体重为例，假设真实数据是 160cm→56.3kg、166cm→60.6kg、172cm→65.1kg、174cm→58.5kg、180cm→56.3kg，模型目前预测 `y = kx - 100`，那么损失函数就是：

```
Loss = (160k - 100 - 56.3)² + (166k - 100 - 60.6)² + (172k - 100 - 65.1)²
     + (174k - 100 - 58.5)² + (180k - 100 - 56.3)²
```

**训练的目标就是：找到让 Loss 最小的那个 k**。

### 解法一：正规方程

Loss 是关于 k 的函数，最小值出现在**导数为 0** 的地方（函数的瞬时变化率为 0）。所以直接令 `Loss' = 0`，解方程就能一步求出最优 k。多元情形就是矩阵运算。

但这个方法有个致命前提——**矩阵的逆必须存在**。当特征数量极多、特征之间高度相关（多重共线性）、或者样本数少于特征数时，矩阵不可逆，正规方程直接失效。而且矩阵求逆的复杂度是 O(n³)，特征上万时根本算不动。

所以实际工程中几乎不用正规方程，用的是下面这个方法。

### 解法二：梯度下降

既然一步解不出来，那就**一点点挪**：从随机的 w 出发，每次往 Loss 减小的方向挪一小步，反复迭代直到收敛。

核心更新公式只有一行：

```
w_new = w_old - 学习率 × 梯度
```

**梯度**是函数上升最快的方向，那么**梯度的反方向**就是下降最快的方向——像一个指北针，告诉你往哪走能最快下山。学习率（learning rate）是每一步迈多大。

```python
# 梯度下降的极简实现（单变量）
def gradient_descent(x, y, lr=0.01, epochs=100):
    w, b = 0.0, 0.0
    n = len(x)
    for _ in range(epochs):
        # 1. 前向计算预测值
        y_pred = w * x + b
        # 2. 计算损失对 w 和 b 的偏导
        dw = (2 / n) * sum((y_pred - y) * x)
        db = (2 / n) * sum(y_pred - y)
        # 3. 沿梯度反方向更新
        w -= lr * dw
        b -= lr * db
    return w, b
```

这三步（算预测 → 算梯度 → 更新参数）就是**深度学习训练循环的雏形**，后面 PyTorch 里的 `loss.backward()` 和 `optimizer.step()` 干的完全是这件事，只是梯度由框架自动算。

## 学习率怎么选

学习率是最重要也最容易调错的超参数：

- **太大** —— 一步跨过最低点，来回震荡甚至发散（损失变成 NaN）
- **太小** —— 每步挪一点点，收敛极慢，可能训练几万轮还没到最优
- **经验区间** —— 0.001 ~ 0.01 是个安全的起步范围

判断方法很直观：**把每轮的 loss 画出来**。正常应该平滑下降；如果上下剧烈跳动，说明学习率太大；如果几乎是一条水平线，说明太小。

```python
import matplotlib.pyplot as plt

loss_history = []
# ... 训练循环里记录每轮 loss ...
plt.plot(range(len(loss_history)), loss_history)
plt.xlabel('轮数'); plt.ylabel('损失')
plt.title('损失下降曲线')
plt.show()
```

补充一个常见误区：有人把"梯度爆炸"归咎于学习率太小，其实不准确——**学习率太小只会导致收敛慢，梯度爆炸是学习率太大**造成的。

## 用正则化防过拟合

当特征很多时，线性回归很容易过拟合：模型为了贴合训练数据，把某些特征的权重学得巨大，导致输入稍一变化输出就剧烈波动。

解决办法是在损失函数后面**加一项惩罚**，限制权重不能太大：

```
L1: Loss = MSE + α · Σ|w|
L2: Loss = MSE + α · Σw²
```

- **L1（Lasso）** 会把部分权重压到**恰好为 0**，相当于自动剔除特征
- **L2（Ridge）** 让权重**趋近于 0 但永不为 0**，保留全部特征只是都削弱

```python
from sklearn.linear_model import Ridge, Lasso, ElasticNet

# alpha 越大，惩罚越重，模型越简单
Ridge(alpha=1.0)              # L2
Lasso(alpha=0.01)             # L1
ElasticNet(alpha=0.01, l1_ratio=0.5)  # L1/L2 各半
```

## 回归问题怎么评估

分类问题看准确率，回归问题看误差大小。三个常用指标：

```python
from sklearn.metrics import mean_absolute_error, mean_squared_error
import numpy as np

mae  = mean_absolute_error(y_test, y_pred)                  # 平均绝对误差
mse  = mean_squared_error(y_test, y_pred)                   # 均方误差
rmse = np.sqrt(mse)                                         # 均方根误差
```

一个实用判断技巧：**RMSE 通常略大于 MAE**（因为平方放大了大误差）。如果 RMSE 比 MAE 大非常多，说明数据里有**少数离群点被严重误判**，值得去查一查这些样本是不是异常值。

## 大模型应用开发中的落地

**第一，"加权求和 + 损失 + 梯度下降"这套范式是大模型的根基**。大模型有几千亿个参数，训练逻辑和这里的线性回归没有本质区别——只是 `w` 从一个数变成了一个巨大的张量，梯度由自动微分算，更新由 Adam 优化器做。理解了单变量梯度下降，就能看懂任何模型的训练代码。

**第二，Embedding 相似度计算本质是向量点积**。RAG 里算"query 和文档有多像"，用的余弦相似度，数学上就是两个向量的内积除以模长——和这里的 `wᵀ·x` 是同一个运算家族。

**第三，正则化思想在微调大模型时依然关键**。微调时设的 `weight_decay` 就是 L2 正则化，目的是防止模型为了贴合小数据集而把预训练好的权重改得面目全非（这叫灾难性遗忘）。经验值：微调 BERT 用 `weight_decay=0.01`，学习率 `2e-5`，就是在这对矛盾之间取平衡。

## 小结

线性回归的完整链条是：**写出预测公式 y = wᵀx + b → 用 MSE 定义损失函数 → 求梯度 → 沿反方向更新参数 → 反复迭代**。正规方程能一步解出但不适用大规模场景，梯度下降是工业界的标准做法，而学习率和正则化决定了这个过程的稳定性和泛化能力。
